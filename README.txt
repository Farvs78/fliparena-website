FlipArena static website (October 2026)

FILES
- index.html: complete responsive one-page website (no build tools required)
- favicon.svg: FlipArena browser icon

HOW TO PREVIEW
Open index.html in a web browser.

HOW TO PUBLISH
Upload the contents of this folder (not the folder itself) to a static web host such as Cloudflare Pages, Netlify or GitHub Pages. Configure fliparena.co.uk and www.fliparena.co.uk as custom domains in the host dashboard, then use ONLY the DNS values your host gives you in Namecheap. Do not overwrite MX, SPF, DKIM or DMARC records; these support your business email.

BEFORE PUBLICATION
- Confirm accurate trading name and proprietor details.
- Add a proper UK address for service of documents wherever required by applicable trading disclosure rules; do not publish a home address without considering privacy.
- Check whether website privacy information and additional terms are needed for the actual data processing and services used.
- Verify that hello@fliparena.co.uk works.
- Make sure the domain spelling is fliparena.co.uk (not flipareana.co.uk).

No cookies, trackers, web fonts, contact forms, external scripts or third-party image assets are included.
